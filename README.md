# Fish 对话音声 1.4.7

提取聊天中的 Talk-Emo 音声段，通过 Fish Audio 合成并保存音频。支持音色库、按语言分派音色、聊天页快速切换、逐段播放、默认音色试听、多角色屏蔽、后台生成、进度和本地音频保留数量管理。插件本身不调用 LLM。

## 三语言世界书

Fish-Dialogue.json 与提供的文件逐字节一致。插件只改变启用状态，升级时为避免 UID 冲突可分配新 UID；不会改写标题、正文、提示词、示例或其他参数。

| 语言选项 | 唯一启用条目 |
| --- | --- |
| 中文 | FA_FORMAT · 中文 |
| 日语 | FA_FORMAT · 日语 |
| 英语 | FA_FORMAT · 英语 |

新安装默认中文；保留老用户语言设置。原文模式供旧消息和普通双引号兼容使用，不提供第四份提示词。变更下拉选项后点“应用语言”才会改变世界书状态。

协议：`<Talk-Emo>角色名|zh|"[happy] 台词"</Talk-Emo>`，语言字段可为 zh、en、ja。所有声音标签原样发送。展示隐藏与逐段按钮保持现有逻辑。正则仅在发送历史给模型时过滤音声段，不删除原始消息。

## 音色库与多语言音色

点“从 Fish 同步”会通过 `GET /model?self=true` 读取你账号里**已创建或已收藏**的音色。Fish 接口没有单独的“收藏”筛选参数，该接口返回的正是这两类。也可以手动填入名称与音色 ID。同步只读取，不会修改或删除 Fish 上的任何音色。

音色自带语言标记（`ja-JP` 归一化为日语）；未标注语言的音色视为通用，在三种语言槽位里都可选。

选择优先级：

```
聊天页快速切换  >  角色绑定  >  全局默认音色
```

- 聊天页输入框上方的三个下拉只对**当前聊天**生效，切换后立即停止当前队列。
- 设置面板的“默认音色”和“角色音色”都按中文/日语/英语分开填写；某语言留空即回落到上一级。
- 语言取自 `Talk-Emo` 协议的语言字段，所以同一条回复里的中文与日文可以各用各的音色。
- 旧配置（单个音色 ID）自动兼容，会同时填充三个语言槽位，不会丢失。

## 安装

1. 在sillytavern中安装此扩展程序。
2. 在酒馆 config.yaml 启用如下配置并重启：

enableCorsProxy: true

3. 填写自己的 API Key，点“从 Fish 同步”拉取音色库。模型文本框默认 s2.1-pro-free。选择中文、日语或英语，点“安装 / 挂载世界书”。

## 使用与数据

- “新回复自动配音”和“聊天序号音频生成”仅生成、保存，不自动播放；聊天内按钮控制播放。
- 默认音色旁的“试听默认音色”会发起试听，再次点击停止。
- 音频保存在浏览器 IndexedDB（按扩展实例隔离），含音频及角色/音色等索引，默认保留 200 个，可选 1–10000。清除网站数据会一并删除。
- “保存API KEY”将 Key 存到酒馆账户设置，清空再保存可删除。已有用户的本地配置不会因更新而清空。
