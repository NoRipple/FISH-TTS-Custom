## 音色管理

顶栏魔法棒菜单里的「Fish 配音管理」打开弹窗。这是插件唯一的入口——酒馆扩展设置面板里不再保留 Fish 的任何配置项。弹窗分四页：音色库 / 搜索音色 / 快速克隆 / 设置。

**音色库**：按组列出音色，每条可以改名称、勾选激活、试听。组头有「全选 / 全部启用 / 全部禁用 / 改名 / 删除组」；顶部的批量条可以把勾选的音色一次性移动到某个组或批量启用、禁用。分组只是标签，删除组只把成员移到「未分组」，不会删掉音色。

**搜索音色**：搜索 Fish 全站公开音色库，按相关度排序。请求走 Fish 网页版在用的 `GET /model/web`（带 `title`、`language`、`sort_by=score`），不加 `self` 参数，所以搜的是公共库而不是你的账号库。这条请求必须直连 `api.fish.audio`：酒馆的 `/proxy/` 只转发 URL、会丢掉 `Authorization` 头，Fish 收到匿名请求后只会返回默认热门列表。直连是跨域请求，需要在酒馆 `config.yaml` 里设置 `enableCorsProxy: true` 并重启，否则页面会提示连接失败。点「添加」会让你选一个组，组名留空就是「未分组」；组名不存在会自动新建。添加只写入本地，不会改动 Fish 账号里的任何东西。

**快速克隆**：导入一段 10–30 秒的参考音频，填名称、语言和逐字稿，保存后就是一条普通音色，可用于角色绑定。用的是 Fish 的一次性克隆（one-shot）：参考音频随每次合成请求一起上传，服务器不保存，也不占你说的克隆槽位。代价是每次合成都要重传这段音频。

合成时代理走插件自带的服务端插件 `plugins/fish-voice-server/`（酒馆启动时自动加载，挂在 `/api/plugins/fish-voice-server/`）。原因见文末「安装」——浏览器既不能直连 `api.fish.audio`（没有 CORS 头），也不能让二进制穿过 `/proxy/`。

参考音频存在浏览器的 IndexedDB 里，扩展没有写磁盘的权限。面板底部显示占用并支持「清理全部参考音频」；单条音色删除时会一并清掉它的音频。清除网站数据会连音频一起删除，换浏览器需要重新导入。

> 逐字稿必须和音频里说的话一字不差，包括标点。这是 Fish 的硬性要求，不一致会明显降低克隆音质。

点输入框右上角的「生成逐字稿」，会把当前选中的音频交给阿里百炼的 `qwen-audio-3.1-asr-flash` 识别。识别结果只是填进输入框，**不会自动保存**——语音识别经常听错人名和标点，请对着音频核对过再点「保存到音色库」。语言选「通用」时不带语言提示，选中文/日语/英语才会告诉模型按对应语言转写。

百炼的地址、模型和密钥在「设置 → 连接 → 逐字稿识别」里填。模型名必须写 `qwen-audio-3.1-asr-flash`；控制台示例里带 `-message` 后缀的名字不存在，调用会返回 `url error, please check url！`。

## AI 生成音色描述

音色库页面里，描述为空的音色右侧有「✨ 生成描述」，组头有「一键补充 N」——后者只补这一组里描述为空的那些音色。两者都调用**酒馆当前选中的聊天补全来源**，用的是你在酒馆里已经配置好的 Base URL 和密钥，插件本身不保存这些凭据。

提示词里给了模型音色名、所属分组、已有描述，外加一段试听音频（多模态）。模型直接输出一段 40–100 字的中文描述，原样写进「音色描述」字段，不经过任何二次加工。

- 已有描述的条目不显示按钮，批处理也会跳过它们——手写的描述不会被覆盖。
- 如果酒馆当前模型不接受音频输入，会自动退回纯文字推断再试一次，日志里会记一条警告。
- 调用失败时，出错原因以红字显示在那条音色或那个组的下方，不会静默失败。
- 批量补充是串行执行的：一条一条调用，避免把你的账号打到限流。


## 三语言世界书

Fish-Dialogue.json 与提供的文件逐字节一致。插件只改变启用状态，升级时为避免 UID 冲突可分配新 UID；不会改写标题、正文、提示词、示例或其他参数。

| 语言选项 | 唯一启用条目 |
| --- | --- |
| 中文 | FA_FORMAT · 中文 |
| 日语 | FA_FORMAT · 日语 |
| 英语 | FA_FORMAT · 英语 |

新安装默认中文；保留老用户语言设置。原文模式供旧消息和普通双引号兼容使用，不提供第四份提示词。变更下拉选项后点“应用语言”才会改变世界书状态。

协议：`<Talk-Emo>角色名|zh|音色名"[happy] 台词"</Talk-Emo>`，语言字段可为 zh、en、ja。第三段（语言字段与左引号之间）是可选的音色名：写了就按它找音色，留空则完全是旧格式 `角色名|zh|"台词"`（仍只有两个 `|`，逐字节兼容）。所有声音标签原样发送。展示隐藏与逐段按钮保持现有逻辑。正则仅在发送历史给模型时过滤音声段，不删除原始消息。

## 音色库与多语言音色

点“从 Fish 同步”会通过 `GET /model?self=true` 读取你账号里**已创建或已收藏**的音色。Fish 接口没有单独的“收藏”筛选参数，该接口返回的正是这两类。也可以手动填入名称与音色 ID。同步只读取，不会修改或删除 Fish 上的任何音色。

音色自带语言标记（`ja-JP` 归一化为日语）；未标注语言的音色视为通用，在三种语言槽位里都可选。

选择优先级（从高到低）：

```
模型第三字段音色名  >  角色绑定  >  角色名匹配音色库  >  全局默认音色
```

- 模型在 `<Talk-Emo>` 第三字段写出的音色名优先级最高；可以是音色库里的 ID、中文名、日文名或罗马音别名。
- 角色绑定：弹窗「设置 → 音色与角色绑定 → 角色绑定」里为某角色手动选择的音色。
- 角色名匹配：未手动绑定的角色，若其名字与某个**已激活**音色同名（忽略空格/全半角/常见标点），自动使用该音色。
- 全局默认音色：以上都没有时的兜底。
- **自动选择音色**（默认开）：控制“模型第三字段”和“角色名匹配”两步；关闭后只用角色绑定与默认音色。
- **自动多人配音**（默认开）：逐句按各角色音色合成；关闭后所有句子统一用当前语言的默认音色。
- 默认音色只在弹窗「设置 → 快速开始」里维护；聊天页不再有音色选择器。
- “角色音色”按中文/日语/英语分开填写；某语言留空即使用默认音色。
- 语言取自 `Talk-Emo` 协议的语言字段，所以同一条回复里的中文与日文可以各用各的音色。
- 旧配置（单个音色 ID）自动兼容，会同时填充三个语言槽位，不会丢失。旧版本写在聊天元数据里的逐聊天音色会在首次加载时并入默认音色，不覆盖已有值。

## 内置音色与名册同步

- “导入内置音色（28）”把 fish-roster.json 里 28 位《偶像大师 闪耀色彩》角色（含中文/日文名、罗马音、Fish 音色 ID 与使用指南）并入音色库；首次安装会尝试自动导入一次。
- 音色库每条都有“激活”勾选框。**未激活的音色不会写进世界书名册，也不参与角色名自动匹配。**
- “同步名册到世界书”把“已激活”的音色按中文/日语/英语分别写进对应语言条目末尾的受管区块（`<!-- FISH_VOICE_ROSTER_START -->` 之间）。重复同步幂等，不改动提示词正文；取消激活后再同步即从名册移除。这是手动操作，不会自动重写世界书。
- 每个音色的简短使用指南（≤60 字）已预生成写入数据（fish-roster.json / voice-guides.json），显示在音色库条目下方；名称可随时修改，改后同样用于角色名匹配。

## 并发

合成默认最多同时发起 **10** 个请求，可在“最大并发请求数”里调整（1–10）。并发越高出音越快，但 Fish 有速率上限：日志出现 HTTP 429 时请调低。对 429 和 503 插件会按 `Retry-After` 自动退避重试，最多两次；其余错误不重试并立即停止队列，避免在鉴权或额度问题上反复空跑。

注意酒馆的 `enableCorsProxy` 是服务端转发，并发数同样会变成服务端的并发出站连接。数值过高时酒馆终端可能出现 `MaxListenersExceededWarning` 之类的连接数告警，调低即可。

## 安装

1. 在sillytavern中安装此扩展程序。
2. 在酒馆 config.yaml 启用如下配置并重启：

enableCorsProxy: true

3. 填写自己的 API Key，点“从 Fish 同步”拉取音色库。模型文本框默认 s2.1-pro-free。选择中文、日语或英语，点“安装 / 挂载世界书”。

## 使用与数据

- “新回复自动配音”和“聊天序号音频生成”仅生成、保存，不自动播放；聊天内按钮控制播放。
- 默认音色旁的“试听默认音色”会发起试听，再次点击停止。
- 音频保存在浏览器 IndexedDB（按扩展实例隔离），含音频及角色/音色等索引，默认保留 200 个，可选 1–10000。清除网站数据会一并删除。
- “保存API KEY”将 Key 存到酒馆账户设置，清空再保存可删除。已有用户的本地配置不会因更新而清空。

## 聊天页显示台词

弹窗「设置 → 快速开始 → 聊天页显示」里的 **在前端显示台词** 默认关闭，保持旧行为：语音段只显示播放/重播按钮和序号。开启后，每段 `<Talk-Emo>` 在同一行显示为 `角色名：「台词」`，按钮紧随其后，播放中的段落会高亮。

该开关只影响渲染：`displayText` 仍只挂在 `AFTER_REGEX` 钩子上，`message.mes` 原文、发送给模型的提示词、以及世界书协议都不受影响。关闭开关后刷新聊天即恢复原样。

## 安装（1.8.0 起需要两个位置）

1. 扩展本体放 `data/<用户>/extensions/FISH-TTS-Custom/`，和以前一样。
2. 服务端插件放酒馆根目录的 `plugins/fish-voice-server/`，里面需要带 `package.json` 和已安装的 `node_modules/`（`fish-audio` 依赖）。放好后重启酒馆一次。

确认是否加载成功：浏览器打开 `/api/plugins/fish-voice-server/status`，看到 `{"ok":true,"sdk":"ready"}` 就对了。若显示 `sdk:"missing"`，说明 `fish-audio` 没装好，在该目录执行 `npm install --omit=dev`。

这一步是 1.8.0 才有的。为什么非这么做不可：`/v1/tts` 只接受 `application/json` 和 `application/msgpack`，而内联 `references`（一次性克隆）明确只支持 MessagePack；浏览器直连 `api.fish.audio` 会被 CORS 拦死；酒馆的 `/proxy/` 用 `JSON.stringify(req.body)` 转发，二进制必然被毁。所以只能让代码在酒馆自己的 Node 进程里跑。
