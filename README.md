# Fish 对话音声 1.5.1

提取聊天中的 Talk-Emo 音声段，通过 Fish Audio 合成并保存音频。支持音色库、按语言分派音色、聊天页快速切换、逐段播放、默认音色试听、多角色屏蔽、后台生成、进度和本地音频保留数量管理。插件本身不调用 LLM。1.5.0 新增：内置 28 位闪耀色彩音色、模型第三字段指定音色、世界书名册同步、音色激活开关、自动选择音色 / 自动多人配音。1.5.1 修正：内置闪耀色彩音色默认仅限日语，不再出现在中文/英文名册。

## 三语言世界书

Fish-Dialogue.json 与提供的文件逐字节一致。插件只改变启用状态，升级时为避免 UID 冲突可分配新 UID；不会改写标题、正文、提示词、示例或其他参数。

| 语言选项 | 唯一启用条目 |
| --- | --- |
| 中文 | FA_FORMAT · 中文 |
| 日语 | FA_FORMAT · 日语 |
| 英语 | FA_FORMAT · 英语 |

新安装默认中文；保留老用户语言设置。原文模式供旧消息和普通双引号兼容使用，不提供第四份提示词。变更下拉选项后点“应用语言”才会改变世界书状态。

协议：`<Talk-Emo>角色名|zh|音色名"[happy] 台词"</Talk-Emo>`，语言字段可为 zh、en、ja。第三段（语言字段与左引号之间）是可选的音色名：写了就按它找音色，留空则完全是旧格式 `角色名|zh|"台词"`（仍只有两个 `|`，逐字节兼容）。所有声音标签原样发送。展示隐藏与逐段按钮保持现有逻辑。正则仅在发送历史给模型时过滤音声段，不删除原始消息。

## 音色库与多语言音色

点“从 Fish 同步”会通过 `GET /model?self=true` 读取你账号里**已创建或已收藏**的音色。Fish 接口没有单独的“收藏”筛选参数，该接口返回的正是这两类。也可以手动填入名称与音色 ID。同步只读取，不会修改或删除 Fish 上的任何音色。

音色自带语言标记（`ja-JP` 归一化为日语）；未标注语言的音色视为通用，在三种语言槽位里都可选。

选择优先级（从高到低）：

```
模型第三字段音色名  >  角色绑定  >  角色名匹配音色库  >  全局默认音色
```

- 模型在 `<Talk-Emo>` 第三字段写出的音色名优先级最高；可以是音色库里的 ID、中文名、日文名或罗马音别名。
- 角色绑定：设置面板“角色音色”里为某角色手动选择的音色。
- 角色名匹配：未手动绑定的角色，若其名字与某个**已激活**音色同名（忽略空格/全半角/常见标点），自动使用该音色。
- 全局默认音色：以上都没有时的兜底。
- **自动选择音色**（默认开）：控制“模型第三字段”和“角色名匹配”两步；关闭后只用角色绑定与默认音色。
- **自动多人配音**（默认开）：逐句按各角色音色合成；关闭后所有句子统一用当前语言的默认音色。
- 设置面板的“默认音色”和聊天页输入框上方的音色开关**是同一份设置**，改任意一处另一处同步。
- “角色音色”按中文/日语/英语分开填写；某语言留空即使用默认音色。
- 语言取自 `Talk-Emo` 协议的语言字段，所以同一条回复里的中文与日文可以各用各的音色。
- 旧配置（单个音色 ID）自动兼容，会同时填充三个语言槽位，不会丢失。旧版本写在聊天元数据里的逐聊天音色会在首次加载时并入默认音色，不覆盖已有值。

## 内置音色与名册同步

- “导入内置音色（28）”把 fish-roster.json 里 28 位《偶像大师 闪耀色彩》角色（含中文/日文名、罗马音、Fish 音色 ID 与使用指南）并入音色库；首次安装会尝试自动导入一次。
- 音色库每条都有“激活”勾选框。**未激活的音色不会写进世界书名册，也不参与角色名自动匹配。**
- “同步名册到世界书”把“已激活”的音色按中文/日语/英语分别写进对应语言条目末尾的受管区块（`<!-- FISH_VOICE_ROSTER_START -->` 之间）。重复同步幂等，不改动提示词正文；取消激活后再同步即从名册移除。这是手动操作，不会自动重写世界书。
- 每个音色的简短使用指南（≤60 字）已预生成写入数据（fish-roster.json / voice-guides.json），显示在音色库条目下方；名称可随时修改，改后同样用于角色名匹配。

## 并发

合成默认最多同时发起 **10** 个请求，可在“最大并发请求数”里调整（1–10）。并发越高出音越快，但 Fish 有速率上限：日志出现 HTTP 429 时请调低。对 429 和 503 插件会按 `Retry-After` 自动退避重试，最多两次；其余错误不重试并立即停止队列，避免在鉴权或额度问题上反复空跑。

注意酒馆的 `enableCorsProxy` 是服务端转发，并发数同样会变成服务端的并发出站连接。数值过高时酒馆终端可能出现 `MaxListenersExceededWarning` 之类的连接数告警，调低即可。

## 安装

1. 在sillytavern中安装此扩展程序。
2. 在酒馆 config.yaml 启用如下配置并重启：

enableCorsProxy: true

3. 填写自己的 API Key，点“从 Fish 同步”拉取音色库。模型文本框默认 s2.1-pro-free。选择中文、日语或英语，点“安装 / 挂载世界书”。

## 使用与数据

- “新回复自动配音”和“聊天序号音频生成”仅生成、保存，不自动播放；聊天内按钮控制播放。
- 默认音色旁的“试听默认音色”会发起试听，再次点击停止。
- 音频保存在浏览器 IndexedDB（按扩展实例隔离），含音频及角色/音色等索引，默认保留 200 个，可选 1–10000。清除网站数据会一并删除。
- “保存API KEY”将 Key 存到酒馆账户设置，清空再保存可删除。已有用户的本地配置不会因更新而清空。
